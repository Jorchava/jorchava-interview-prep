# Senior Frontend Interview Master Course

A private, chain-structured interview-preparation reference for senior
frontend / web-games developer roles — built to the depth of an actual
high-bar engineering interview loop, not a Q&A list.

Every topic is treated as a chain of connected concepts (e.g. closures →
scope → lexical environment → garbage collection → private state → module
pattern → currying → memoization → hooks/composables), each covered at
six-part depth: theory, the exact spoken interview answer, live-coding,
follow-up questions, junior-vs-senior contrast, and production examples
from large-scale frontend/game codebases.

Built and run on the Personal Agentic Dev Framework this repo was
generated from — see `AGENTS.md`, `SKILLS.md`, and `PROJECT_CONTEXT.md`
for the governance every session runs under, and `docs/` for the content
spec and roadmap.

## Structure

- `docs/product-brief.md` — what this is, who it's for, why it exists
- `docs/architecture.md` — the six-part content spec, the module/chain
  model, and the exceptions for System Design / Live Coding / Behavioral
- `docs/roadmap.md` — the full session backlog: 97 sessions across 17
  modules, tracked as it's built
- `sessions/` — one prompt per development session
- `book/` — the actual content, organized by module (created as sessions
  complete)
