# Product Brief: Senior Frontend Interview Master Course

> Written before `docs/architecture.md` — Phase 0, the "why" that
> justifies every content decision that follows.

---

## One-Line Pitch

A private, chain-structured interview-preparation reference built to the
depth of an actual senior/staff frontend + web-games engineering loop —
concept-to-concept reasoning the way a senior engineer would actually
walk an interviewer through it, not a list of Q&A pairs.

---

## Who Is This For

One person: Jorchava, preparing for senior frontend / web
frontend-with-games-experience roles at high-bar tech companies. No
secondary audience for now — see Non-Goals.

---

## What This Demonstrates

> The anti-"just another leetcode list" section.

- **Depth over breadth.** Closures aren't a definition — they're a chain
  (scope → lexical environment → garbage collection → private state →
  module pattern → currying → memoization → hooks/composables) the way a
  real interviewer would actually probe it, not a flashcard.
- **Production judgment, not toy examples.** Every topic ends in how it
  actually shows up in a large-scale frontend or web-game codebase
  working across multiple teams.
- **Interview craft, not just knowledge.** A natural 1-3 minute spoken
  answer, a whiteboard-realistic live-coding round, and the follow-up /
  trick-question layer interviewers use specifically to separate senior
  from mid — prepared for on purpose, not as an afterthought.

## Smallest Demonstrable Version

One fully-worked chain: Module 1's closures arc (closures → lexical
environment → garbage collection → private state → module pattern →
currying → memoization → hooks/composables), at full six-part depth.

If this reads as genuinely senior — no padding, no wiki-style
definitions, an interview answer that sounds like a person talking — the
format is proven, and the remaining 96 sessions are the same exercise at
scale, not a new problem to solve.

---

## How This Differs From a Generic Version

A generic version is a list of interview questions with short answers —
that already exists, in a hundred places, for free. This one is
structured as interconnected chains matching how senior interviewers
actually probe (follow-up after follow-up until they find the edge of
real understanding), paired with production examples calibrated
specifically to large-scale frontend and web-game codebases, and a
live-coding section built for whiteboard conditions rather than
takeaway-style problems.
